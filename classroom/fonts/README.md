# Polices locales du carnet

Fraunces (titres et cartes) et Nunito Sans (interface et lecture) sont fournies sous SIL Open Font License 1.1. Les deux licences originales sont conservées ici et embarquées dans le HTML autonome. Aucun appel à Google Fonts n'est effectué pendant le jeu.

Sources officielles :
- https://github.com/google/fonts/tree/main/ofl/fraunces
- https://github.com/google/fonts/tree/main/ofl/nunitosans

Les fichiers WOFF2 latin et latin étendu ont été récupérés le 4 octobre 2026 depuis l'API CSS officielle Google Fonts. `sources.json` conserve leurs URL et empreintes SHA-256. `fonts.css` déclare les poids variables (Fraunces 400–700, Nunito Sans 400–800) ; `build-extra.js` remplace les références locales par des données intégrées. Les accents espagnols et français sont inclus.
